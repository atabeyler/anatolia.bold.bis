# Repository Agent Instructions

These instructions apply to all automated development agents working in this repository.

## Workflow
- Commit directly to the original `main` branch unless explicitly instructed otherwise by the repository owner.
- Keep commits focused, atomic, and descriptive.

## Commit and Pull Request Style
- Use professional, human-written commit messages.
- Use professional pull request titles and descriptions.
- Do not include statements, signatures, trailers, emojis, or wording that indicates AI assistance.
- Do not mention AI tools, language models, automation, or generated content in commits, pull requests, comments, or merge-related text.

## Code Standards
- All source code, comments, documentation, and README files must be written in English.
- All user-facing text must use the internationalization (i18n) system.
- Supported languages: English (default), Turkish, German, French, and Arabic.
- Never hardcode user-facing strings.
